# 🛡️ Doctor Cyber App - User Guide

## 📱 Overview

Doctor Cyber is a comprehensive cybersecurity application designed to provide protection across all digital fronts. The app serves both **regular users** and **administrators** with different access levels and functionalities.

---

## 🔐 Getting Started

### System Requirements
- Android 7.0 (API level 24) or higher
- Internet connection required for authentication and content updates
- Google Play Services (for Firebase integration)

### Initial Setup
1. **Download and Install** the Doctor Cyber app from your app store
2. **Launch the app** - you'll see the login screen
3. **Create an account** or use existing credentials to log in

---

## 🚀 How to Use the App

### 1. 🔐 Login Process

#### For Administrators:
1. Open the Doctor Cyber app
2. Enter **Email:** `admin@drcyber.com`
3. Enter **Password:** `admin`
4. Tap **Login**
5. You'll be redirected to the **Admin Panel**

#### For Regular Users:
1. Open the Doctor Cyber app
2. Enter your registered email address
3. Enter your password
4. Tap **Login**
5. You'll be redirected to the **Main App**

#### Creating New User Account:
1. On the login screen, tap **"Sign Up"**
2. Enter your email address
3. Enter a secure password
4. Confirm your password
5. Tap **"Sign Up"**
6. You'll be automatically logged in

## ⚙️ Admin Panel Interface

### Accessing Admin Panel
1. Login with admin credentials (`admin@drcyber.com` / `admin`)
2. You'll be automatically redirected to the Admin Panel

### Admin Panel Features

#### 📝 **Create New Post**
1. **Select Category:** Choose from dropdown menu
   - Home
   - About
   - Contact
   - Services (with subcategories)

2. **Select Subcategory** (for Services):
   - Cyber
   - Web3
   - XR
   - IoT
   - Charity

3. **Enter Post Details:**
   - **Title:** Enter a descriptive title
   - **Description:** Write detailed content
   - **Image:** Tap "Select Image" to choose from gallery

4. **Upload Post:**
   - Tap **"Upload Post"**
   - Wait for upload progress
   - Confirmation message will appear

#### 📋 **Manage Existing Posts**
1. **View Posts:** See all created posts in a list
2. **Edit Posts:** Tap edit button to modify content
3. **Delete Posts:** Remove posts you no longer need

#### 🖼️ **Image Management**
- **Supported Formats:** JPG, PNG
- **Size Recommendations:** Optimized for mobile viewing
- **Upload Process:** Automatic compression and Firebase storage

## 🛠️ Troubleshooting

### Common Issues & Solutions

#### Login Problems:
- **Incorrect Credentials:** Double-check email and password
- **Network Issues:** Ensure stable internet connection
- **Account Not Found:** Contact administrator for account creation

#### Content Not Loading:
- **Check Internet:** Ensure stable connection
- **Restart App:** Close and reopen the application
- **Clear Cache:** Clear app data in device settings

#### Image Upload Issues:
- **File Size:** Ensure images are not too large
- **Format:** Use JPG or PNG formats only
- **Permissions:** Grant storage permissions to the app

#### Admin Panel Access:
- **Credentials:** Use exact admin credentials provided
- **Permissions:** Ensure you have admin privileges
- **Network:** Stable internet required for Firebase operations
